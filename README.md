# 딸깍 AD 도구함

경제방송 AD 업무를 딸깍 한 번으로 — 도구 다섯 개를 하나로 묶은 윈도우 프로그램이에요.

| 도구 | 하는 일 |
|---|---|
| 딸깍 수익률 | 장 마감 후 KRX 정규장 시세로 수익률 엑셀 업데이트 + 시트별 탑5 |
| 딸깍 그래프 | DART 숫자로 종목 실적 차트·표 슬라이드 |
| 딸깍 실적 | 잠정실적 공시 알림 + 카톡 문구 + 실적통 CG 한글 파일 |
| 딸깍 피피티 | 위원님 차트 자료(사진·한글·PPT)를 프로그램 PPT 폼으로 |
| 딸깍 반통 | 대본 → 반통 작성 + 반통 취합 |

## 받기
오른쪽 **[Releases]** → 가장 위 버전 → `딸깍 AD 도구함_v….zip` 받기

1. zip 파일 오른쪽 클릭 → [속성] → **[차단 해제]** 체크 → [확인]
2. 압축을 풀고 `딸깍 AD 도구함.exe` 실행
3. 파란 "Windows의 PC 보호" 창이 뜨면 **[추가 정보] → [실행]**
4. 처음 실행 안내에서 DART 인증키를 넣어요 (그래프·실적에만 필요, opendart.fss.or.kr 에서 무료 발급)

이미 쓰고 있다면 도구함을 켤 때 새 버전 안내가 떠요 → [지금 업데이트]. 설정·인증키는 그대로 남아요.

> 이 저장소에는 설치 파일만 올려요. DART 인증키 같은 개인 정보는 프로그램에 들어 있지 않고, 각자 PC에만 저장돼요.
